# บันทึกรายรับรายจ่าย

เว็บสำหรับบันทึกรายรับรายจ่ายส่วนตัว ใช้ HTML/CSS/JavaScript ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

## วิธีใช้
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย หรือเปิด GitHub Pages ให้ repo นี้ก็ได้

## ฟีเจอร์
- เพิ่ม แก้ไข และลบรายการรายรับหรือรายจ่าย พร้อมหมวดหมู่ วันที่ และบันทึกสั้นๆ
- สรุปรายรับ รายจ่าย และยอดคงเหลือของแต่ละเดือน
- กราฟแท่งแสดงรายจ่ายแยกตามหมวดหมู่
- กรองรายการให้แสดงทั้งหมด หรือเฉพาะรายรับ หรือเฉพาะรายจ่าย
- ส่งออกเป็น JSON หรือ CSV (เปิดใน Excel แล้วภาษาไทยไม่เพี้ยน) และนำเข้าไฟล์ JSON กลับมาได้

## การเก็บข้อมูล
ข้อมูลเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องที่ใช้งานเท่านั้น ไม่ได้ส่งไปที่เซิร์ฟเวอร์ไหน
ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะไม่ตามไปด้วย จึงควรส่งออกไฟล์ JSON ไว้สำรองเป็นระยะ
